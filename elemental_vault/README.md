# Elemental Vault v0 — hydrogen-first foundation

Scope: elemental vault only. No Dual-LVT, avatars, consciousness, NFT, or AI-driven selection.

## Status
An executable **conservation ledger**, NOT an atomic physics solver or a successful discovery of helium. The pp-I net reaction is a **known physics pathway provided as a law/example**, not independently inferred from hydrogen. The resulting He-4 nucleus is an unvalidated candidate and not a prediction of its mass, stability, abundance, or synthesis rate.

## Run
From repository root: `python -m unittest discover -s elemental_vault -p 'test_*.py' -v`.
No third-party Python packages needed. The SQL schema is for a **new isolated Neon project/database**, not the existing Lexicon or Open Diagram databases.

## Physics and limitations
The ledger conserves electric charge, baryon number, and electron-family lepton number. It does not yet conserve energy/momentum numerically, simulate weak-interaction rates, solve quantum nuclear structure, account for plasma temperatures, or prove a reaction is energetically or kinetically accessible. The net pp-I expression has 2 photons as a bookkeeping shorthand; photon multiplicity is not generally fixed by the net nuclear reaction, and neutrino energies are not computed.

## Blinded validation
Reference data must be loaded in a separate schema/database and withheld from generator queries. Report every empirical constant and any preloaded reaction rule; never label a known supplied reaction as a discovered pathway.
