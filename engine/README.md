# engine

The Manifold Engine's execution logic: `seed_hydrogen_replication.py` builds
the high-fidelity Hydrogen Seed, `exponential_instancing_v1.math` notes the
binary-doubling instancing scheme used to grow that seed into clouds and
stars, `manifold_projection_core.md` describes the recursive domain-nesting
("manifold_inward") core, and `supernova_compiler_logic.md` covers how a
star's life cycle is compiled into the heavier elements that fill out the
Periodic Table. See [VISION.md](../VISION.md) for how these pieces fit into
the Triple-Purpose Manifold.
