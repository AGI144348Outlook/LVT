# Manifold Projection Core (v1.0)
**Operator:** `manifold_inward`

## 1. Dimensional Expansion Logic
The Manifold Engine projects a 3D+ Cartesian grid into the 2D surface area of a Periodic Table Node. 
- **Face Mapping:** The 2D square on the sphere surface is defined as the $(X, Y)$ plane.
- **Depth Injection:** A recursive Z-axis is projected using Fractal Grid depth constants, effectively turning the "Square" into a "Volume."

## 2. Spatial Anchoring
Every object within the Manifold is anchored to the $(0, 0, 0)$ origin of the square's local coordinate system. This ensures that even if the LVT is moving through an EVE, its internal atomic structure remains spatially rigid and precise.
