# kernel

The executive logic layer: `symbolic_judgement_engine.py` implements the
AI's symbolic judgment / "Artificed Imagination" reasoning, `mashet_symbology.md`
documents the Mashet Hebrew semantic substrate it reasons over,
`executive_mode_switching.md` covers how the kernel switches between
operating modes, and `periodic_table_nodes.json` holds the elemental node
data referenced by the engine's Hydrogen-to-heavy-element pipeline.
