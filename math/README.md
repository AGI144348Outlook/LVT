# math

Physical constants and the atomic/gravitational equations the engine builds
on: `constants_and_units.json` holds shared physical constants and units,
`hydrogen_field_equations.md` documents the wave-function math behind the
Hydrogen Seed, `gravitational_collapse_logic.md` covers the equations used to
take a hydrogen cloud through star formation and supernova, and
`manifold_projection_geometry.md` describes the geometry used to project the
Fractal Grid across scales.
